# Naveen Kumar B — Portfolio

A custom-designed, responsive personal portfolio for **Naveen Kumar B**, a Computer Science & Data Science undergraduate at ATME College of Engineering.

The visual direction combines editorial typography, a cinematic portrait composition, a Three.js orbital object, warm paper project panels and a midnight interface.

## Live site
[https://naveengowda11.github.io/Portfolio2/](https://naveengowda11.github.io/Portfolio2/)

## Run locally
This is a static website. From the project root, run:
```bash
python -m http.server 8000
```
Then open http://localhost:8000.

You can also use the VS Code Live Server extension.

## Built with
- HTML5
- CSS3 (responsive layout, animation and reduced-motion support)
- Vanilla JavaScript
- Three.js (loaded as an ES module from jsDelivr)
- Google Fonts: Space Grotesk, Manrope and DM Mono

## Project structure
- `index.html` — all portfolio sections and content
- `style.css` — visual system, responsive layouts and animations
- `app.js` — navigation, rotating intro text, scroll progress and reveal effects
- `main.js` — Three.js orbital object in the hero
- `assets/naveen-profile.jpg` — professional portrait
- `assets/favicon.svg` — favicon
