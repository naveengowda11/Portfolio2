# Naveen Kumar B — 3D Developer Portfolio

A responsive, futuristic developer portfolio featuring an interactive Three.js hero, animated sections, project showcases, skills, experience, education and contact links.

## Tech stack
- HTML5, CSS3 and vanilla JavaScript
- Three.js via jsDelivr ES module
- Google Fonts: Manrope and DM Mono

## Run locally
Run a local server from the repository root:

```bash
python -m http.server 8000
```

Open http://localhost:8000.

## Project structure
- `index.html` — portfolio content and layout
- `style.css` — visual design and responsive styling
- `app.js` — navigation, animated intro text and scroll effects
- `main.js` — interactive Three.js 3D hero scene
- `assets/favicon.svg` — site icon

## Deploy with GitHub Pages
1. Open **Settings → Pages**.
2. Choose **Deploy from a branch**.
3. Select `main` and `/ (root)`, then save.
4. GitHub will display the published URL in the Pages settings.

## Customize
Edit the relevant files above. Update project descriptions and links in `index.html`, styles in `style.css`, interactions in `app.js`, and the 3D scene in `main.js`.
